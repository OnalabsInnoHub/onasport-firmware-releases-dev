# Onasport Firmware Releases Development

Welcome to the Onasport Firmware Releases repository for DEVELOPMENT. This repository contains the firmware update files for Onasport devices for purposes outside of customers: for development, quality assurance and beta testers environments.

To update a new firmware file upload the .sfb file into the repository and update appropriately the fw_info.json file. 
Description can be added to provide more context to that specific firmware version files.
This repository is the source for the onasport verify app to fetch latest firmware versions for users.
